SPIN THE WHEEL - MOBILE READY

Files:
- index.html
- style.css
- script.js

Run locally:
1. Extract this ZIP.
2. Open index.html in your browser, or use VS Code Live Server.

Deploy for free using GitHub Pages:
1. Sign in to GitHub and create a new public repository (for example: spin-wheel).
2. Upload index.html, style.css, and script.js to the repository root.
3. Go to repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder / (root), then Save.
6. Wait for GitHub Pages to publish. Your public URL will be shown in the Pages section.
7. Open that URL on your phone.

Mobile layout is responsive and supports phone-sized screens.
